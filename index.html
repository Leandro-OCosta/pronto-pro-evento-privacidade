Política de Privacidade — Pronto pro Evento

Última atualização: 18 de setembro de 2026.

O Pronto pro Evento é um aplicativo de checklist para organização de eventos. Ele foi projetado para funcionar localmente e sem necessidade de conta.

Dados armazenados

Os nomes dos eventos, datas e itens dos checklists são armazenados somente no dispositivo do usuário por meio do armazenamento local do aplicativo. O desenvolvedor não recebe esses dados e não mantém servidor ou banco de dados remoto para o aplicativo.

Coleta e compartilhamento

O aplicativo não coleta nem compartilha dados pessoais ou de uso com o desenvolvedor, anunciantes ou empresas de análise.

O aplicativo não contém cadastro ou login, anúncios, analytics, rastreamento, sincronização em nuvem ou notificações de marketing.

Compartilhamento iniciado pelo usuário

Quando o usuário escolhe compartilhar um checklist, o aplicativo abre o menu de compartilhamento do Android. O próprio usuário escolhe o aplicativo ou serviço de destino. Esse conteúdo só é enviado ao destino escolhido pelo usuário.

Permissões

O aplicativo não solicita permissões sensíveis para localização, câmera, microfone, contatos, SMS, chamadas ou arquivos pessoais.

Exclusão de dados

Os dados podem ser apagados pelo próprio usuário excluindo os eventos dentro do aplicativo ou limpando os dados/desinstalando o aplicativo no Android. Como não há conta nem servidor remoto, não existem dados de conta armazenados pelo desenvolvedor.

Crianças

O aplicativo é uma ferramenta geral de organização e não foi projetado especificamente para crianças.

Alterações desta política

Se funcionalidades futuras alterarem a forma como os dados são tratados, esta política e a declaração de Segurança dos dados do Google Play deverão ser atualizadas antes da publicação da nova versão.
